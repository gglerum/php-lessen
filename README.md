# PHP Development Course

Dit is het lesmateriaal voor een PHP cursus van 39 weken. We beginnen bij de basis van PHP en eindigen bij het ontwerpen van onderhoudbare applicaties. Je hoeft geen PHP te kennen, maar een beetje programmeer ervaring (bijvoorbeeld Python) helpt. We vergelijken PHP daarom regelmatig met Python.

De cursus bestaat uit drie delen.

## Part 1: PHP basis (week 1 t/m 13)
[Part 1](Part%201%20(week%201%20to%2013)/) begint met de ontwikkelomgeving, variabelen, functies en arrays. Daarna volgen classes en OOP, HTML formulieren en sessions, en werken met een database. Onderweg bouwen we een paar voorbeelden die steeds uitgebreid worden, zoals Galgje en een bibliotheek systeem.

## Part 2: Laravel (week 14 t/m 26)
In [Part 2](Part%202%20(week%2014%20to%2026)/) werken we met het Laravel framework. Daar staat een opdeling van de Laravel documentatie in hapklare brokken, zodat je weet waar je moet beginnen.

## Part 3: Design principles (week 27 t/m 39)
[Part 3](Part%203%20(week%2027%20to%2039)/) gaat over hoe je code schrijft die je over een half jaar nog kunt aanpassen: design principles, clean code, SOLID, GRASP, refactoring, design patterns en Domain Driven Design.

## Voorbeelden draaien
Elke les heeft een `example` map met kleine voorbeelden die je zelf kunt uitvoeren. Dit zijn losse projecten, er is geen gezamenlijke installatie nodig. Ga in de terminal naar de map van het voorbeeld en start het:

- Console voorbeelden: `php console.php`
- Web voorbeelden: `php -S localhost:8090`
- Voorbeelden met een `composer.json`: eerst één keer `composer install`

## Labs
Bij een aantal lessen horen interactieve labs. Hierin loop je stap voor stap door de code en zie je wat er in het geheugen gebeurt, voorspel je de uitkomst van een stukje code of zoek je een bug. De labs staan in de `lab` map bij het voorbeeld en zijn gelinkt vanuit de les.
