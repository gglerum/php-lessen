Lab 3: Wat gebeurt er?

Hieronder staat de class BankAccount. Lees de code, kies wat je denkt dat er gebeurt en controleer je antwoord. Daarna lees je waarom.

    De class BankAccount die in alle scenario's wordt gebruikt 
    class BankAccount
{
    public readonly string $owner;
    private int $balance;

    public function __construct(string $owner, int $balance = 0)
    {
        $this->owner = $owner;
        $this->balance = $balance;
    }

    public function deposit(int $amount): void
    {
        if ($amount <= 0) {
            echo "Je kunt alleen een positief bedrag storten\n";
            return;
        }

        $this->balance = $this->balance + $amount;
    }

    public function withdraw(int $amount): void
    {
        if ($amount > $this->balance) {
            echo "Onvoldoende saldo\n";
            return;
        }

        $this->balance = $this->balance - $amount;
    }

    public function getBalance(): int
    {
        return $this->balance;
    }
}

    De scenario's staan in een script met declare(strict_types=1);.
