Lab 2: Wat gebeurt er?

Hieronder staan vier classes, waarvan Combatant abstract is. Je ziet ook wat Enemy aan loot heeft. Lees de code, kies wat je denkt dat er gebeurt en controleer je antwoord. Daarna lees je waarom.

    De classes die in alle scenario's worden gebruikt 
    abstract class Combatant
{
    protected string $name;
    protected int $health;
    protected int $armorRating;

    public function __construct(string $name, int $health, int $armorRating)
    {
        $this->name = $name;
        $this->health = $health;
        $this->armorRating = $armorRating;
    }

    public function takeDamage(int $damage): void
    {
        $this->health = $this->health - max(0, $damage - $this->armorRating);
    }

    public function getName(): string
    {
        return $this->name;
    }

    public function getHealth(): int
    {
        return $this->health;
    }

    abstract public function attack(): int;
}

class Player extends Combatant
{
    private int $experiencePoints = 100;

    public function attack(): int
    {
        return 10 + intdiv($this->experiencePoints, 10);
    }
}

class Npc extends Combatant
{
    public function attack(): int
    {
        return 1;
    }
}

class Enemy extends Combatant
{
    private string $loot;
    private int $threatLevel;

    public function __construct(string $name, int $health, int $armorRating, string $loot, int $threatLevel)
    {
        parent::__construct($name, $health, $armorRating);
        $this->loot = $loot;
        $this->threatLevel = $threatLevel;
    }

    public function getLoot(): string
    {
        return $this->loot;
    }

    public function attack(): int
    {
        return $this->threatLevel * 4;
    }
}

    De scenario's staan in een script met declare(strict_types=1);. Kom je een class tegen die hier niet staat, dan staat hij bij het scenario.
