## Clean Code
Lees voor deze les de volgende onderwerpen door:

- Meaningful names
- Functions
- Comments
- Principle of least astonishment (https://en.wikipedia.org/wiki/Principle_of_least_astonishment)
- Premature optimization (https://en.wikipedia.org/wiki/Program_optimization#When_to_optimize)

In [clean_code.md](./clean_code.md) worden namen, functies, comments, het principe van de minste verrassing en premature optimization uitgelegd aan de hand van code uit Part 1. Er staat ook uitleg bij waarom de checklist uit Part 1 meer comments vraagt dan je in de praktijk schrijft. De bijbehorende opgaven staan in [clean_code_opgaven_1.md](./clean_code_opgaven_1.md).
