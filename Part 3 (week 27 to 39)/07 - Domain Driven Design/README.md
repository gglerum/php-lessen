## Domain Driven Design
Lees voor deze lessen de volgende onderwerpen door:

- Domain Driven Design (https://martinfowler.com/bliki/DomainDrivenDesign.html)
- Ubiquitous language (https://martinfowler.com/bliki/UbiquitousLanguage.html)
- Bounded context (https://martinfowler.com/bliki/BoundedContext.html)

Domain Driven Design is verdeeld over twee lessen.

In [ddd_1.md](./ddd_1.md) staan de gedeelde taal, de bounded context, entities en value objects. De bijbehorende opgaven staan in [ddd_opgaven_1.md](./ddd_opgaven_1.md).

In [ddd_2.md](./ddd_2.md) volgen aggregates, repositories, domain services, domain events en het anemic domain model, en wanneer je DDD juist niet gebruikt. De bijbehorende opgaven staan in [ddd_opgaven_2.md](./ddd_opgaven_2.md).

Veel onderdelen ken je al uit de vorige lessen onder een andere naam, zoals Repository, Value Object en Observer. De lessen laten zien hoe ze samen een geheel vormen.
